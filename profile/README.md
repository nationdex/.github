# NDS

Welcome! This is the public GitHub organization for NDS, one of the most passionate open-source development teams so far.

## What we do?

- 🇺🇳 [Nationdex](https://github.com/nationdex/bot) - One of the oldest Ballsdex alternative bots available, aiming to revive and reunite the Ballsdex community by introducing a new alternative solution, hence the name "Project Nationdex 2026", built by actual top-nacht developers.

- 🕶️ [AntamScript](https://github.com/nationdex/antamscript) - The B I G bubensahne ist geil, the B I G alternative to ForgeScript, think beyond forgin', think AntamScriptum.

- 🧳 [Graak](https://github.com/nationdex/graak) - Make binaries of JS/TS projects for every device, including even legacy Windows devices and mobile environments, potentially eliminating many of the limitations meticulously left behind by developers.

- 🎵 [Adi Music](https://github.com/nationdex/music) - Notorious fork of a open-source music player, originally created by adidotzip, now turned into a serious project in HTMX, Alpine.js, UnoCSS, and Astro, with a full PWA system and mobile Flutter app.

- ✔️ [MindVote](https://mindvote.xyz) **CLOSED SOURCE** - The all-in-one Brazilian electoral dashboard with easy-to-understand metrics for everyone to see and comprehend.
